# Immutable SUMO highway-merge snapshot

This directory is a one-way snapshot from the WCDT source commit recorded in
`PROVENANCE.json`. Files in this version directory are immutable. If the source
scenario changes, create `v2`; do not overwrite `v1`.

The copied `scenario_geometry_check.json` contains historical absolute paths
from the source machine. Those fields are evidence only and are never used at
runtime.
