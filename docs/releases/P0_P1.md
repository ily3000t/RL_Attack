# P0/P1 Release — Independent PPO Attack Baseline and SUMO Core

Status: **completed and verified**

## Description

This release establishes `RL_Attack` as an independent Git project for PPO
attack-and-defense research. It separates the third research block from
`WCDT_ACCVP_Attack`, freezes the current highway-merge scenario as an immutable
one-way snapshot, and provides a runnable observation-attack baseline through a
general Stable-Baselines3 categorical-policy interface.

## Implemented

- Independent repository, architecture boundaries, milestone plan, and
  experiment protocol.
- Python 3.10 virtual environment with a fully resolved 35-package lock.
- Explicit threat-model and feature-wise perturbation contracts.
- SB3 categorical PPO adapter with input gradients.
- Random-Uniform, Random-Sign, FGSM-CE, random-start PGD-CE, and
  Categorical-MAD attacks.
- Clean/attacked paired-seed evaluation with attack count, policy-query,
  gradient-evaluation, and actual perturbation-norm accounting.
- Pure Gymnasium SUMO highway-merge environment with the frozen 52-dimensional
  observation, nine actions, legacy default reward, OBB safety metrics, and
  TraCI lifecycle.
- Immutable SUMO scenario provenance with source commit and per-file SHA-256.
- Unified `third_party/upstream` layout and exact commit/submodule lock for
  SA-PPO, CAR-RL, WocaR-RL, PA-AD, ATLA, and Robust-Gymnasium.
- Isolation checks preventing runtime imports from WCDT or paper-code
  repositories.

## Verification

- 23 tests pass in `E:\RL_Attack\.venv`.
- The complete 35-distribution environment matches the resolved lock.
- CartPole PPO training, PGD injection, and evaluation pass end to end.
- SUMO 1.22.0 with TraCI 1.22.0 runs the frozen scenario successfully.
- Git-stored SUMO bytes match the source SHA-256 manifest.
- `WCDT_ACCVP_Attack` remains read-only with no working-tree changes.

## Scope boundary

P0/P1 is the correctness and reproducibility baseline. It does not claim that
FGSM, PGD, or Categorical-MAD is a sufficient robustness audit. P2 and later
releases add robust-training baselines, stronger temporally aware attacks,
adaptive defenses, and layered SUMO victim evaluation.
